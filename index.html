Models and computation
  • The PID controller is in parallel form \(C(s)=K_P+\dfrac{K_I}{s}+\dfrac{K_D s}{s/N+1}\) (\(N\): derivative filter coefficient).
  • With "Enter transfer function", any \(P(s)=N(s)/D(s)\cdot e^{-Ls}\) can be specified. Poles and zeros are computed with the Durand–Kerner method.
  • A controller entered as a transfer function \(C(s)=N_c(s)/D_c(s)\) (proper) is converted to state space. A direct feedthrough term causes no algebraic loop because the plant is strictly proper.
  • In PI-D form, the D term acts only on \(-y\), avoiding the derivative kick at reference steps.
  • The time response is computed in state space (controllable canonical form) with exact zero-order-hold discretization via the matrix exponential, using 4000 steps over the simulation time. Very fast or slow poles do not cause numerical breakdown. If the step is coarse relative to the closed-loop gain crossover frequency, the controller is updated up to 100 times between recorded points. Dead time is represented by an input buffer.
  • Response metrics depend on the reference type (with a disturbance, they are evaluated before it is applied). For step and trapezoid references, rise time (10–90%) and settling time (±2% band) are measured from the start time \(t_0\). For sine references, the amplitude ratio and phase difference are obtained from the Fourier coefficients of the last 1–3 periods and shown alongside the theoretical closed-loop \(T(j\omega)=L/(1+L)\).
  • Measurement noise uses a fixed-seed Gaussian sequence, so the same sequence is used when parameters change.
