# `.claude/` — for the maintainer's AI assistant

This folder is used by [Claude Code](https://claude.com/claude-code), the AI coding assistant the maintainer works with:

- `skills/control-sim-dev/SKILL.md` — the step-by-step development and release procedure (in Japanese), read by Claude Code together with [`CLAUDE.md`](../CLAUDE.md). It also covers publishing to the maintainer's page on claude.ai, which only his accounts can do.

You do not need anything here to use, build, test or contribute to SigmaOmega. The rules that matter for people are in [CONTRIBUTING.md](../CONTRIBUTING.md) (日本語: [CONTRIBUTING.ja.md](../CONTRIBUTING.ja.md)).
